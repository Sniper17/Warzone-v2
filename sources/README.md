# Fontes e prioridade

- Activision / Call of Duty: fonte primária para patch, buff, nerf e mudanças oficiais.
- WZHUB: fonte principal pública para loadouts/classes e ranking META.
- WZStats, CODMunity e WarzoneLoadout: confirmação/fallback.

A API nunca inventa acessórios. Se não houver classe confiável, informa o estado e o buff/nerf oficial disponível.
