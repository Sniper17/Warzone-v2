# Fontes da Warzone API v3

- Activision/Raven Software: fatos oficiais de patch, buff e nerf.
- CODMunity Warzone: status META, pick rate e classe principal.
- WZHUB: confirmação/fallback de classes.
- WarzoneLoadout.games: fallback de classe e novas armas.

A API não inventa acessórios quando as fontes não permitem confirmação.
